# Cashflow Sentinel — v1.0 Definition

## Purpose
Cashflow Sentinel v1.0 is a decision-intelligence soft sensor designed to
detect inventory- and logistics-driven cashflow strangulation early enough
for corrective action.

If a feature does not directly support this purpose, it does not belong
to v1.0.

---

## Scope (Frozen)
v1.0 focuses exclusively on early warning of cashflow risk caused by:
- Inventory dynamics
- Logistics lead times
- Operational turnover behavior

The system is not:
- An ERP
- A financial forecasting system
- An accounting replacement
- A simulation or planning suite

---

## Data Inputs
v1.0 accepts only:
- Sales (aggregated)
- Inventory levels and movements
- Purchases / replenishment
- Basic logistics lead times

No external integrations are required.

---

## Mandatory Indicators
v1.0 must compute, reliably and consistently:

1. Inventory Turnover Velocity
2. Inventory Aging Index
3. Stock-to-Sales Ratio
4. Cash Conversion Cycle (CCC)
5. Inventory Strangulation Index (ISI)

All indicators must be documented and interpretable.

---

## Signal Engine
v1.0 provides a deterministic risk signal:
- GREEN
- YELLOW
- RED

Signals are based on:
- Trend direction
- Rate of deterioration
- Not solely on static thresholds

---

## Explainability Requirement
For any YELLOW or RED state, the system must be able to explain:
- Which indicators are responsible
- What trend is driving the signal
- In business-oriented language

Opaque scoring models are explicitly excluded.

---

## Interface Requirements
v1.0 must include:
- A functional dashboard
- Clear KPI visualization
- Trend visualization
- Risk state visibility

The interface must be understandable by non-technical users.

---

## Validation
v1.0 must be validated using:
- A healthy business scenario
- A progressive deterioration scenario
- A clear cashflow strangulation scenario

Synthetic data is acceptable.

---

## Definition of Done
Cashflow Sentinel v1.0 is considered complete when:

- The analytical pipeline runs without errors
- All mandatory indicators are stable
- Risk signals behave coherently
- The dashboard is usable
- The public README reflects v1.0
- A GitHub Release titled “v1.0 – Commercial MVP” is published

At this point, no additional features may be added to v1.0.
